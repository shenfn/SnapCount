## 0. 文档定位

本文档定义芥子设计系统的**工程实施规范**：Token 命名、生成流程、产物路径、使用方式、扩展规则。

它位于《芥子长期产品与设计基调》（上位原则）和具体代码实现（Swift / Vue / CSS）之间。所有 Token 调整、主题增减、组件样式变更必须先改 SSOT，再经生成脚本产出，最后由本文档解释如何使用。

**适用范围**：iOS SwiftUI 端、PWA Vue 端、Tailwind 预设、未来扩展端。

## 1. 单一数据源（SSOT）原则

### 1.1 什么是 SSOT

`trae-design-system/tokens/design-tokens.json` 是 Token 的**唯一数据源**。任何颜色、字体、间距、圆角、阴影、动效的调整必须从这里开始。

### 1.2 三条铁律

1. **改 SSOT，不改产物**：派生产物（`dist/` 目录下所有文件）由生成脚本自动覆盖，手工修改将被下一次生成抹掉。
2. **每端只消费，不发明**：iOS Swift / PWA CSS / Tailwind Preset 只能引用生成的 Token，不允许在某端私自新增颜色或间距。
3. **生成是可重现的**：在任意干净环境下运行 `node scripts/generate-*.mjs`，应得到完全相同的产物。

### 1.3 修改流程

```
1. 改 tokens/design-tokens.json
2. 运行生成脚本（见第 3 节）
3. 提交 SSOT + 产物到版本库（同一次 commit）
4. 在 iOS / PWA 项目中验证视觉无回归
```

### 2.1 顶层分类

| 分类 | 路径 | 说明 |
|------|------|------|

| `color.alpha_variants` | 颜色 | 常用透明度变体（0.08 / 0.11 / 0.13 / 0.18 等） |
| `color.domains` | 颜色 | **v0.2 新增**：7 个数据域色，全局固定不随主题切换 |
| `color.art` | 颜色 | **v0.2 新增**：艺术版专用色（荧光蓝/朱砂红），功能页面禁用 |
| `time_phases.phases` | 颜色 | 7 时段时间相位调色参数；**v0.2 新增** `transition_minutes` 线性插值规则 |
| `gradient` | 颜色 | 页面背景、须弥背景、品牌渐变 |
| `typography` | 字体 | 字体族 + 11 级字体层级；**v0.2 新增** `numeric` 数字规则与 `roles` 语义角色 |
| `spacing` | 间距 | 12 级间距 + 6 个语义间距 |

| `shadow` | 阴影 | 6 级阴影 + 3 个语义阴影；**v0.2 修正** iOS 端按 palette 解析颜色（主题感知） |
| `motion` | 动效 | 5 级时长 + 5 个曲线 + 5 个语义动效；**v0.2 修正** spring 参数为 0.42/0.82 |
| `glass` | 材质 | 玻璃面板参数；**v0.2 新增** `solid_card` 实卡变体 |
| `stroke` | 描边 | **v0.2 新增**：金线 0.5mm / 卡片描边 / 分隔线 / 聚焦环 |
| `icon` | 图标 | **v0.2 新增**：7 级图标尺寸 + 3 个语义尺寸 |
| `haptics` | 触觉 | **v0.2 新增**：5 个 iOS 触觉反馈语义 |
| `layout` | 布局 | 页面宽度、安全区、Tab Bar 高度（**v0.2 修正** iOS 49 / PWA 72 分列） |
| `z_index` | 层叠 | 6 级 z-index |

### 2.2 命名规范

**颜色语义槽位**（不可改名）：
- `paper` —— 纸张底色，主背景
- `brand` —— 品牌主色，按钮/强调
- `light` —— 辅助亮色，金属点缀
- `space` —— 深空色，深色背景
- `ink` —— 主文字色
- `muted` —— 次要文字色
- `coral` —— 警示/危险色

**间距命名**（t-shirt 风格）：
`xxs → xs → sm → md → lg → xl → xl2 → xl3 → xl4 → xl5 → xl6 → xl7`，对应数值 `2 → 4 → 8 → 12 → 16 → 20 → 24 → 32 → 40 → 48 → 64 → 80`

**字体层级**（与 iOS HIG 对齐）：
`caption2 / caption / footnote / subheadline / body / callout / headline / title3 / title2 / title1 / largeTitle`

### 2.3 语义 Token 优先

代码中应优先使用**语义 Token**（如 `card_padding`），而非原始层级（如 `xl2`）。当未来视觉调整时，只改语义映射即可，无需全代码库替换。

```swift
// 推荐
.padding(JieziSpacing.Semantic.cardPadding)

// 不推荐
.padding(JieziSpacing.xl2)
```

- Node.js ≥ 18（使用原生 ESM，无需安装任何 npm 包）

## 4. iOS SwiftUI 端使用

### 4.1 接入方式（v0.2 起完全自包含）

将生成的 `JieziTheme+Generated.swift` 复制进 iOS 项目（建议 `ios/SnapCount/DesignSystem/`），XcodeGen 的 `sources` 会自动包含，无需改 `project.yml`。

v0.2 起产物**自包含**：颜色工具使用独立命名 `Color(jieziHex:)` / `jieziBlended(with:amount:)`，与手写 `JieziTheme.swift` 里的 `Color(hex:)` / `blended` 不冲突，两个文件可以共存。迁移完成后手写文件可逐步瘦身，只保留 `JieziPageBackground` / `GlassPanel` 等组件，颜色常量改指向 `JieziGeneratedPalette`。

注意：**不要**在视图里直接 `JieziThemeManager()` 新建实例。App 根部用 `@StateObject` 持有 `JieziThemeManager.shared`（或自建单一实例）并 `.environmentObject` 注入，各视图通过 `@EnvironmentObject` 读取。

### 4.2 主题切换

```swift
import SwiftUI

struct SettingsView: View {
    @StateObject private var themeManager = JieziThemeManager()

    var body: some View {
        List(JieziGeneratedPalette.all, id: \.id) { palette in
            Button(action: { themeManager.switchTo(palette.id) }) {
                HStack {
                    Circle().fill(palette.brand).frame(width: 24, height: 24)
                    Text(palette.name)
                    Spacer()
                    if palette.id == themeManager.palette.id {
                        Image(systemName: "checkmark")
                    }
                }
            }
        }
        .environmentObject(themeManager)
    }
}
```

### 4.3 在视图中使用 Token

```swift
struct MyCard: View {
    @EnvironmentObject var themeManager: JieziThemeManager

    var body: some View {
        Text("一段文字")
            .font(JieziFont.body)
            .foregroundStyle(themeManager.palette.ink)
            .padding(JieziSpacing.Semantic.cardPadding)
            .background(themeManager.palette.paper.opacity(0.72), in: RoundedRectangle(cornerRadius: JieziRadius.Semantic.card, style: .continuous))
            .jieziShadow(.lg)
    }
}
```

### 4.4 时间相位调色

```swift
let phase = JieziPhase.at(hour: Calendar.current.component(.hour, from: Date()))
// phase.warmth / brightness / saturation / spaceShift 用于实时调色
// 建议在 JieziThemeManager 中暴露一个 currentAdjustedColors 计算属性
```

### 4.5 渐变背景

```swift
JieziGradient.pageBackground(palette: themeManager.palette)
JieziGradient.sumeruBackground(palette: themeManager.palette)
JieziGradient.brandWash(palette: themeManager.palette)
```

### 4.6 v0.2 新增 API

**语义字体角色**（替代散写的 `.system(size:)`）：

```swift
Text("个人数据平台").font(JieziType.display)          // serif 宋体感大标题
Text("¥1,280").font(JieziType.moneyHero).monospacedDigit()  // rounded 等宽金额，money 系列务必带 monospacedDigit
Text("财务状态").font(JieziType.sectionTitle)
```

**卡片表面**（替代散写的 `white.opacity` 卡片）：

```swift
VStack { ... }.jieziCard(palette: themeManager.palette)              // 玻璃卡：材质 + 宣纸底
HStack { ... }.jieziCard(palette: themeManager.palette, solid: true) // 实卡：列表行/小卡
```

**描边 / 阴影 / 域色 / 触觉**：

```swift
.stroke(JieziStroke.gold_hairline(palette).color, lineWidth: JieziStroke.gold_hairline(palette).width)
.jieziShadow(JieziShadows.Semantic.card(palette))   // 阴影按主题解析，不再是首个主题硬编码
.foregroundStyle(JieziDomainColor.color(for: domain.id))  // 数据域色，不随主题切换
JieziHaptics.absorb()  // 「啵」瞬态：rigid 冲击
```

**时间相位插值**（替代整点跳变）：

```swift
let values = JieziPhase.values(atHour: hour, minute: minute)
// values.warmth / brightness / saturation / spaceShift 在相位边界前后 22.5 分钟内线性混合
```

## 5. PWA Vue 端使用

### 5.1 接入方式（不破坏现有 src/styles/main.css）

将 `dist/pwa/tokens.css` 复制到 `src/styles/jiezi-tokens.css`，在 `main.js` 中引入：

```js
import './styles/jiezi-tokens.css'
```

### 5.2 切换主题

```js
// 切换主题
document.documentElement.setAttribute('data-theme', 'springWood')

// 获取当前主题
const currentTheme = document.documentElement.getAttribute('data-theme') || 'cyan'
```

### 5.3 在 CSS 中使用

```css
.my-card {
  padding: var(--jiezi-spacing-card-padding);
  border-radius: var(--jiezi-radius-card);
  background: var(--jiezi-color-paper);
  color: var(--jiezi-color-ink);
  box-shadow: var(--jiezi-shadow-semantic-card);
  transition: all var(--jiezi-motion-press-duration) var(--jiezi-motion-press-easing);
}

.my-title {
  font-size: var(--jiezi-font-title1-size);
  font-weight: var(--jiezi-font-title1-weight);
  line-height: var(--jiezi-font-title1-line-height);
}
```

### 5.4 在 JS 中使用

```js
import { THEMES, DEFAULT_THEME_PWA, SPACING, RADIUS, DURATIONS, EASINGS } from './styles/tokens.js'

console.log(THEMES) // 全部主题
console.log(SPACING.xl2) // 24
```

| `lotus` | 藕荷余晖 | — | 降低科技感，突出柔软、亲密与长期陪伴 |

| `springWood` | 枯木逢春 | PWA | 第一版正式主题。全暖调的侘寂设计 |
| `temple` | 古刹苔痕 | — | 候选主题。古刹石壁、苔痕与微弱金光 |

### 7.2 新增主题流程

1. 在 `tokens/design-tokens.json` 的 `color.themes` 数组追加新对象（必填 `id` / `name` / `description` / `colors` 七槽位）
2. 运行生成脚本
3. 验证 iOS / PWA / Tailwind 三端均能切换到新主题
4. 视觉走查对比度、可读性、深色模式兼容性

### 7.3 主题不是皮肤

参见《芥子长期产品与设计基调》第 9.3 节：主题不应只是替换颜色和背景图。一个成熟主题可以重新解释材质、光线、声音和空间，但必须与同一套核心价值保持一致。

## 8. 时间相位规范

### 8.1 七时段

| 时段 | 时间 | 暖度 | 亮度 | 饱和度 | 空间偏移 |
|------|------|------|------|--------|---------|
| 深夜 | 0-5 | -12 | -24 | -8 | -18 |
| 破晓 | 5-8 | +10 | +8 | -4 | -7 |
| 晨光 | 8-11 | +5 | +14 | 0 | 0 |
| 日中 | 11-15 | 0 | +18 | -6 | +5 |
| 午后 | 15-18 | +8 | +8 | +2 | 0 |
| 暮色 | 18-21 | +18 | -2 | +8 | -8 |
| 入夜 | 21-24 | -4 | -16 | -2 | -15 |

### 8.2 应用原则

- 用户在凌晨 3 点打开 App，应自动调暗 `paper`，加深 `space`
- 时间相位是**叠加在主题之上**的微调，不改变主题语义
- 用户可关闭时间相位（设置项），但主题不可关闭
- **v0.2 新增**：相邻相位在边界前后 `transition_minutes/2`（当前 22.5 分钟）内线性插值，禁止整点跳变；iOS 用 `JieziPhase.values(atHour:minute:)` 取插值结果

## 9. 字体规范

### 9.1 字体层级

参见 SSOT `typography.scale`。共 11 级，与 iOS HIG 字体语义对齐：

| Token | iOS Size | iOS Weight | PWA Size | PWA Weight | 用途 |
|-------|----------|-----------|----------|-----------|------|
| `caption2` | 11 | regular | 11 | 400 | 极小说明，时间戳 |
| `caption` | 12 | regular | 12 | 400 | 副说明 |
| `footnote` | 13 | regular | 13 | 400 | 脚注、列表辅助文字 |
| `subheadline` | 15 | regular | 14 | 400 | 副标题、卡片副标题 |
| `body` | 17 | regular | 15 | 400 | 正文 |
| `callout` | 16 | medium | 14 | 500 | 强调正文、按钮文字 |
| `headline` | 17 | semibold | 16 | 600 | 列表项标题 |
| `title3` | 20 | semibold | 18 | 600 | 卡片标题 |
| `title2` | 22 | semibold | 20 | 600 | 页面次级标题 |
| `title1` | 28 | bold | 24 | 700 | 页面主标题 |
| `largeTitle` | 34 | bold | 30 | 700 | 大标题、空状态标题 |

### 9.2 字体族

- iOS：默认 `.system`，可选 `.rounded` / `.serif`
- PWA：默认 `Inter`，可选 `SF Pro Rounded` / `Lora` / `JetBrains Mono`

### 9.3 语义字体角色（v0.2 新增）

scale 是骨架，roles 是衣品。「芥子味」的两条字体铁律：

1. **标题用衬线**（serif / 宋体感）——呼应新中式的宣纸气质
2. **金额用圆体等宽数字**（rounded + monospacedDigit / tabular-nums）——呼应账本的对齐感

| 角色 | 层级 | 字族 | 用途 |
|------|------|------|------|
| `display` | title1 28 | serif | 页面主标题（如「个人数据平台」） |
| `displayLarge` | largeTitle 34 | serif | 空态大标题、启动页书法字位 |
| `moneyHero` | largeTitle 34 | rounded + 等宽 | 财务主数字（净额估算、大金额输入） |
| `moneyCard` | title2 22 | rounded + 等宽 | 卡片级金额、日汇总 |
| `moneyInline` | headline 17 | rounded + 等宽 | 列表行内金额 |
| `sectionTitle` | title3 20 | system | 区块标题 |
| `cardTitle` | headline 17 | system | 卡片内标题、列表行主文字 |
| `button` | callout 16 semibold | system | 按钮文字 |
| `chip` | footnote 13 medium | system | 分类 Chip |
| `metricLabel` | caption 12 | system | 指标说明文字 |

## 13. 动效规范

### 13.1 时长

| Token | ms | 用途 |
|-------|----|------|
| `instant` | 0 | 即时反馈 |
| `fast` | 150 | 按压、悬停 |
| `normal` | 250 | 标准过渡 |
| `slow` | 400 | Sheet 出现 |
| `deliberate` | 600 | 刻意动画 |

### 13.2 曲线

| Token | Bezier | 用途 |
|-------|--------|------|
| `standard` | cubic-bezier(0.4, 0, 0.2, 1) | 标准过渡 |
| `decelerate` | cubic-bezier(0, 0, 0.2, 1) | Sheet 出现 |
| `accelerate` | cubic-bezier(0.4, 0, 1, 1) | Sheet 消失 |
| `spring` | iOS `spring(response:0.42, dampingFraction:0.82)` / bezier(0.34, 1.56, 0.64, 1) | 弹性反馈（**v0.2 修正**：参数与视觉实验室动效决定一致，生成器不再丢弃参数） |
| `gentle` | cubic-bezier(0.45, 0, 0.55, 1) | 柔和过渡 |

### 13.3 语义组合

- `press`：fast + standard
- `sheet_present`：slow + decelerate
- `sheet_dismiss`：normal + accelerate
- `page_transition`：normal + standard
- `ripple`：normal + decelerate

## 14. 边界与异常处理

### 14.1 主题切换的脏状态

**风险**：切换主题时，已渲染的视图可能保留旧颜色。

**处理**：
- iOS：`JieziThemeManager` 是 `ObservableObject`，所有引用 `palette` 的视图自动刷新
- PWA：CSS Variables 天然支持热切换，无需 JS 介入
- 关键：禁止在视图内部缓存颜色值，必须通过 `themeManager.palette.xxx` 或 `var(--jiezi-color-xxx)` 实时引用

### 14.2 时间相位的性能

**风险**：每分钟更新一次时间相位可能导致全屏重绘。

**处理**：
- 时间相位更新频率 = 1 次/小时，不是每分钟
- iOS：在 `scenePhase` 变化或前台切换时重新计算
- PWA：用 `setInterval` 每小时检查一次，使用 `requestAnimationFrame` 应用

### 14.3 深色模式

**当前状态**：v0.1 暂不主动支持系统深色模式（`prefers-color-scheme: dark`）

**临时方案**：
- iOS：在 Info.plist 中声明 `UIUserInterfaceStyle = Light`，强制浅色
- PWA：通过 `<meta name="color-scheme" content="light">` 限制

**未来路径**：当某个主题（如 `xuan` 玄青须弥）作为深色模式时，通过 SSOT 标记 `is_dark: true`，生成脚本自动产出到 `@media (prefers-color-scheme: dark)` 块中

### 14.4 对比度合规

**风险**：某些主题的 `ink` 与 `paper` 对比度可能低于 WCAG AA（4.5:1）

**处理**：
- 后续添加生成脚本 `scripts/check-contrast.mjs`，自动校验所有主题的 `ink/paper` / `muted/paper` / `brand/paper` 对比度
- 校验失败时阻止生成，并打印警告

### 14.5 缓存与持久化

- iOS：主题 ID 持久化到 `UserDefaults`（key: `jiezi.theme.id`）
- PWA：主题 ID 持久化到 `localStorage`（key: `jiezi.theme.id`）
- 切换账号、登出时**不清除**主题偏好（属于用户设备级偏好，不属于账号数据）

## 15. 版本演进

### 15.1 版本号规则

SSOT 使用语义化版本：`MAJOR.MINOR.PATCH`

- `MAJOR`：Token 命名/结构调整，需要全端同步改造
- `MINOR`：新增主题、新增 Token 分类
- `PATCH`：数值微调、新增 alpha 变体

### 15.2 兼容性承诺

- iOS / PWA 双端 Token 必须同步发布
- 删除 Token 视为 Breaking Change，必须升级 MAJOR
- 新增 Token 不影响现有代码
