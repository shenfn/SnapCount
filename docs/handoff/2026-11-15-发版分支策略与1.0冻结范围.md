## 分支约定

- `main`：只放可提交 App Store 的发版基线。合并前完成 Release 构建、回归测试、TestFlight 真机验证和 App Store Connect 元数据检查。
- `release/1.0-zh`：本次中文发版候选分支，记录 1.0 的冻结范围和验证结论。它从 `feature/release-1.0-local-gates` 创建，不承载后续日常开发。
- `feature/*`：新功能开发。
- `fix/*`：问题修复。
- `test/*`、`docs/*`：验证和文档工作。

## 1.0 暂不开放的能力

开关集中在 `ios/SnapCount/Models/NativeSettings.swift` 的 `JieziReleaseCapabilities`：

- 月度报告里的 AI 联动提问：隐藏联动分析入口，并在 `AppState` 层拒绝生成请求。
- 云端同步：设置页隐藏绑定、预览、同步和关闭同步操作；本机记录和导出仍可用，登录仍可用于 Hosted AI。
- BYOK：设置页隐藏 BYOK 选项和 Key 表单；已有设备上的 BYOK 偏好会迁移为“关闭识别”，不会删除 Keychain 数据。

这三块的数据库、Provider、Edge Function 和同步代码保留在仓库中，后续只需重新打开能力开关并完成专项验证，不需要恢复历史提交或重新接线。

## 时间口径

- ISO 8601 字段继续保存绝对时间点。
- 面向用户的陪伴文案和 Prompt 展示时间统一使用 `Asia/Shanghai`。
- iOS 本地表达层不再使用设备的 `TimeZone.current` 作为默认值。
- Hosted 本地表达入口从带时区的 `clientCapturedAt` 重建展示时间，避免旧的 UTC 墙上时间覆盖正确时间。

因此，设备显示 11:00、采集时间为同一时刻时，AI 只能收到北京时间 11:00，不会再把它解释成凌晨 03:00。
