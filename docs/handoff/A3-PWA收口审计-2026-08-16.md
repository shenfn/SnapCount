### 2.3 数据域 adapter 输入边界

`src/domains/detailAdapters.js` 与 `src/adapters/domain/*` 的展示函数仍接收 Store 读模型，例如 `getMetricItems(store, domain)`、`getRecentRecords(store, domain)`。这属于展示读取模型耦合，不是 Domain 对 UI/HTTP/Supabase 的反向依赖；`domain_forbidden_imports` 仍为 0。

本轮保留该形状，后续若要收窄，应先定义稳定的 domain read model，再按行为测试迁移，不能只为减少参数而批量改调用方。

### 2.4 RPC 契约清单

`governance:arch` 继续报告 `rpc_contracts` 为人工清单。这与 A1 基线及 A3/A5 目标一致：当前已有 Repository/Feature 契约测试，但尚无跨端共享注册表，不能宣称自动覆盖全部 RPC。

### 2.5 Store 兼容门面

PWA-069 已删除无消费者的 `upsertAccountEntry`、`voidAccountEntries` 及公开出口，并用全量源边界测试阻止 PWA 产品代码重新直调对应数据库 primitive。其余 `useStore` 编排和兼容门面仍有消费者，不能因为文件仍大就作为本轮失败依据。
