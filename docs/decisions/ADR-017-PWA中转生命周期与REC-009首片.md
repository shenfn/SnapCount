# ADR-017：PWA 中转生命周期与 REC-009 首片

> 日期：2026-08-16
>
> 状态：已由 REC-009 实现并合并 main（PR #72）

## 决策

1. 中转生命周期按 Feature/Repository 渐进收拢，`useStore` 继续作为兼容门面。
2. 下一片只实现 REC-009：三次重试上限与人工归档、修复、丢弃出口。
3. `retry_count`、第四次拒绝和中转状态流转由 Edge/数据库权威；PWA 只映射结果和控制入口。
4. 当前 PWA 归档的跨表非原子差异单独建立数据库/生命周期任务，不在 REC-009 里用客户端逻辑掩盖。
5. iOS 已有 `InboxRepositoryProtocol`，作为动作 transport 形状参考；PWA 与 iOS 共享 REC-009 场景，不强行统一页面组件。
6. `system-spec-overview` 的历史 WIP 不作为实现来源；本线只使用已合并到 main 的记录生命周期规格和新建脱敏 fixture。

## 原因

中转状态同时涉及图片、AI 重试、正式记录、账户影响、删除清理和用户隔离，完整抽离的回归面高。REC-009 有明确服务端判定、可独立验证、用户价值清晰，适合作为最小垂直切片。归档原子性则需要数据库事实和回滚策略，必须独立处理。

## 禁止事项

- 不把 `retry_count` 的上限复制成 PWA 自己的业务权威。
- 不因第四次重试失败而从本地队列删除记录。
- 不以“页面显示成功”替代 Edge/RPC 成功。
- 不在本片顺手修复归档事务、历史孤儿或账户规则。
