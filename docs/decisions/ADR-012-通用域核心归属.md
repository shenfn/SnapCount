# ADR-012：通用域候选规则归属生产共享核心

> 状态：已接受（CORE-010 边界评估决策）
>
> 日期：2026-08-15
>
> 关联任务：CLEAN-001/A2、CORE-010

## 决策

1. 通用域规则归属 `supabase/functions/_shared/expression-core/`，生产不得继续依赖 `tools/ai-validation/expression-planner/lib/generic-domain-candidates.mjs`。
2. 保留 `prepareDomainRecords`、`generateIncomeCandidates` 和 `generateBuiltinDomainCandidates` 作为稳定兼容门面，避免 Edge Planner 在迁移中同时改编排。
3. 门面内部按共享基础、income、food、sleep 和 wallet 模块拆分；sport/reading 继续走通用指标路径。
4. wallet 独立拥有金额来源、账户身份、资产/负债类型和快照先后规则，并使用独立契约 fixture；不得复用普通域的中位数比较。
5. `domainProfile` 由调用方注入，核心只消费已验证的纯数据，不加载、不生成、不持久化 profile。
6. Planner Lab 原路径保留薄 wrapper；Edge、fallback 和 Lab 通过同一生产门面使用同一份规则。

## 原因

当前文件没有 IO，迁移边界成立；但它同时承载六个领域和高风险钱包安全规则。原样复制会把实验室文件名变成新的生产单体，继续放大修改半径，也会让钱包规则和普通健康域共享错误的比较假设。稳定门面加内部职责拆分可以同时保留迁移兼容性和长期依赖方向。

## 禁止事项

- 不得在 CORE-010 中修改候选 semantic key、结构化输出、证据、置信度或选择提示；
- 不得把睡眠去重和因果时间过滤在各领域重复实现；
- 不得把钱包变化解释为消费、还款、转账或因果关系；
- 不得放宽钱包账户身份、类型或严格时间门禁；
- 不得让核心读取数据库、JSON、profile、环境变量或设备 API；
- 不得把 `render-contract`、PWA、iOS 或 Edge `index.ts` 拆分混入本决策；
- 不得因文件变小而删除兼容门面或 fallback。

## 回滚

若共享 fixture、Planner 回归或双运行时检查发现行为差异，恢复 Edge 旧 wrapper/import 并保留失败证据；不得先修改 fixture 断言再宣称迁移通过。
