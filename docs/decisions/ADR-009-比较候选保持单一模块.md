# ADR-009：比较候选保持单一模块

> 状态：已接受（CORE-007 规格前置决策）
>
> 日期：2026-08-15
>
> 关联任务：CLEAN-001/A2、CORE-007

## 决策

1. 商户日/周比较与分类周比较共同归属 `supabase/functions/_shared/expression-core/comparison-candidates.mjs`。
2. 两个导出使用独立契约组，但共享时间窗口、金额汇总、指标变化、证据和候选构造内部实现。
3. 本次迁移不抽取公共 `comparison-primitives`，不改统计公式和候选结构。
4. Planner Lab 保留原路径作为兼容 wrapper；Edge 直接引用生产核心。

## 原因

两个入口共享大量事实规则且共同演进。当前拆文件需要重复规则或公开内部 helper，增加漂移面；机械迁移整个模块更容易证明迁移前后行为一致。

## 禁止事项

- 不得在迁移中改变上海时区、周一起点、同期截止时间或至少 3 个活跃日的门槛。
- 不得把 pending、无效金额或无关类别混入已确认汇总。
- 不得把 comparison、render contract、资格门或评分合并为一个模块。
- 不得仅因文件行数而拆出没有独立业务契约的 helper 模块。

## 回滚

若共享 fixture、既有测试或完整 Planner 发现行为差异，恢复 Edge 旧导入并保留失败证据；不得通过修改期望输出掩盖差异。
