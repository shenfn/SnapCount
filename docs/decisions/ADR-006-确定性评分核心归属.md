# ADR-006：确定性评分核心归属

> 状态：已接受（CORE-004 规格前置决策）
>
> 日期：2026-08-15
>
> 关联任务：CLEAN-001/A2、CORE-004

## 决策

1. 候选确定性评分和评分摘要的唯一权威位于 `supabase/functions/_shared/expression-core/deterministic-scoring.mjs`。
2. 评分独立消费资格门结果，不复制资格逻辑或放宽 surface 拒绝。
3. Planner Lab 的 `deterministic-scoring.mjs` 保留为兼容 wrapper；Edge 生产入口直接引用 `_shared`。
4. 曝光、偏好、表面阈值和排序摘要都属于评分契约的一部分，迁移时保持版本和输出字段。

## 原因

评分模块位于资格门之后、计划选择之前，纯函数且已有 9 项特征测试。将它独立迁移可以切断一条生产 `tools/` 依赖，同时保留资格、评分、选择三个可审计阶段，避免把“不可展示”与“低分”混为一谈。

## 禁止事项

- 不得在评分层重新计算候选事实、证据或资格。
- 不得因为迁移而调整阈值、公式、曝光隔离、偏好边界或版本。
- 不得把候选生成、选择、渲染或实体配置顺手并入本切片。

## 回滚

若 CI 或共享 fixture 发现结构化评分差异，恢复 Edge 到旧导入并保留失败 fixture；不得通过放宽分数断言或删除旧字段掩盖差异。
