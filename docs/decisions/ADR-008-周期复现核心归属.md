# ADR-008：周期复现核心归属

> 状态：已接受（CORE-006 规格前置决策）
>
> 日期：2026-08-15
>
> 关联任务：CLEAN-001/A2、CORE-006

## 决策

1. 同名记录上一次间隔候选的唯一权威位于 `supabase/functions/_shared/expression-core/recurrence-candidates.mjs`。
2. 周期复现只消费已归一化事件和事实契约，不负责实体别名配置、数据库读取或资格/评分。
3. Planner Lab 原路径保留为兼容 wrapper；Edge 生产入口直接引用 `_shared`。
4. `normalized_key`、`known_at`、`count_in_facts` 和时间精度是周期复现的硬输入边界，不能在迁移中放宽。

## 原因

周期复现模块是独立纯函数，已有完整的边界测试，且与 comparison 的统计窗口和 cross-record 的关系推断边界清晰。先迁移它可减少一条生产 `tools/` 依赖，不改变候选选择或表达文案。

## 禁止事项

- 不得以展示名或模糊匹配代替 normalized name 精确匹配。
- 不得把晚于当前记录的 `known_at` 记录当作 previous。
- 不得把 date-only 事件强行转成分钟间隔。
- 不得因为迁移而顺手并入 comparison、cross-record、generic-domain 或实体配置。

## 回滚

若 CI 或共享 fixture 发现候选结构差异，恢复 Edge 到旧导入并保留失败 fixture；不得通过放宽时间或因果过滤掩盖差异。
