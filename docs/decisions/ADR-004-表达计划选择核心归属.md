# ADR-004：表达计划选择核心归属

> 状态：已接受（CORE-002 规格前置决策）
>
> 日期：2026-08-15
>
> 关联任务：CLEAN-001/A2、CORE-002

## 决策

1. 表面容量、候选排序、覆盖排除、容量、多样性、周期冷却和 fallback 选择的唯一权威位于 `supabase/functions/_shared/expression-core/plan-selection.mjs`。
2. Planner Lab 的 `expression-plan.mjs` 保留为兼容 wrapper，不重新实现选择规则。
3. 候选生成、资格门、评分和渲染契约暂不随本切片迁移，继续由 Planner 编排层调用。
4. `surface_fallback` 和 `exact_fact_fallback` 保持两个独立出口；单一事实源不等于单一路径。

## 原因

该模块无 IO、无环境依赖，已有 Planner 回归和 fallback fixture 覆盖，迁移风险低于候选生成、比较和跨记录关系模块。将它归入生产共享核心可以先切断一个 `tools/` 生产依赖，同时不改变候选事实和评分算法。

## 禁止事项

- 不得在 Lab wrapper 中复制或修改选择规则。
- 不得因为迁移而改变候选分数、阈值、容量、fallback 标记或排除原因。
- 不得把候选生成、资格门、评分或渲染契约顺手并入本切片。

## 回滚

若 CI 或对比 fixture 发现输出差异，恢复 Edge 入口到旧导入并保留 `_shared` 实现、失败 fixture 和差异记录；不删除旧 wrapper 或生产核心文件。
