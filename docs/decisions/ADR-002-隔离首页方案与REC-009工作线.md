# ADR-002：隔离首页方案与 REC-009 工作线

> 日期：2026-08-15
>
> 状态：已确认方向，具体归档动作待授权

## 决策

1. `ios-home-v3-native` 不再作为首页候选；当前只继续评估 PR #25 的 `ios-home-redesign`。
2. 不把 `system-spec-overview` 视为系统架构总览，也不将其 REC-009 WIP 合并到治理线。
3. REC-009 中转站重试/人工出口功能暂不进入当前主线；未来需要时从最新 `main` 创建独立修复分支。

## 背景

`ios-home-v3-native` 与 PR #25 都修改 iOS 首页，继续并行会产生两套首页事实源和重复 macOS 验证。`system-spec-overview` 的实际内容是中转站状态动作、重试策略和多份本地规格草稿，主线已经具备基础重试次数限制，不需要把这批未提交 WIP 当作治理基础。

## 边界

- 本 ADR 不授权删除 worktree、分支、远端引用或未跟踪文件。
- `ios-home-v3-native` 的 `.playwright-cli/` 不属于产品源码，但仍需在归档/删除前按 C1 恢复流程处理。
- REC-009 如果重新启动，必须补 PWA/iOS/Edge 共享状态动作契约和跨端测试。
