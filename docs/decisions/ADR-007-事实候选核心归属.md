# ADR-007：事实候选核心归属

> 状态：已接受（CORE-005 规格前置决策）
>
> 日期：2026-08-15
>
> 关联任务：CLEAN-001/A2、CORE-005

## 决策

1. 支出当前记录、日聚合和商户实体首次出现候选的唯一权威位于 `supabase/functions/_shared/expression-core/fact-candidates.mjs`。
2. 事实候选只消费已归一化事件和事实契约，不负责实体别名配置、数据库读取或资格/评分。
3. Planner Lab 原路径保留为兼容 wrapper；Edge 生产入口直接引用 `_shared`。
4. `count_in_facts`、本地日期和 `entity_first_seen` 是候选生成的硬输入边界，不能在迁移中放宽。

## 原因

事实候选模块规模较小，只依赖已迁入生产核心的数值/金额函数，已有 8 项特征测试，且与 recurrence、comparison 和 generic-domain 候选边界清晰。先迁移它能减少一条生产 `tools/` 依赖，同时不改变跨记录关系和周期语义。

## 禁止事项

- 不得在候选层补写事实契约、猜测实体或把别名首次出现当成实体首次出现。
- 不得因为迁移而改变上海时区日期过滤、金额 0、pending 状态或候选编号/曝光 key。
- 不得把 recurrence、comparison、generic-domain 或实体配置顺手并入本切片。

## 回滚

若 CI 或共享 fixture 发现候选结构差异，恢复 Edge 到旧导入并保留失败 fixture；不得通过减少证据或放宽事件过滤掩盖差异。
