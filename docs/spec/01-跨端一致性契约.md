# 芥子跨端一致性契约

> 规格编号：CROSS-PLATFORM-001
>
> 文档版本：0.2
>
> 状态：试行
>
> 适用平台：PWA、iOS、Edge Function、Supabase

## 1. 契约目的

本文档规定 PWA 与 iOS 必须共享的业务含义，以及可以由平台自由决定的表现差异。

它不要求两个平台使用相同的组件、文件结构或交互控件；它要求用户在两个平台看到的事实、状态、数据影响和导航目标不互相矛盾。

## 2. 契约优先级

发生冲突时，按以下顺序处理：

1. 已发布的安全、隐私和数据隔离约束。
2. 本契约明确的跨端不变量及本地优先数据生命周期契约。
3. 数据路径的事务权威：iOS 本地事务、同步协议或云端 RLS/RPC。
4. 领域详细规格中的字段、状态和验收场景。
5. PWA 已稳定运行的云端行为和平台视觉实现。

如果现有 PWA、iOS 和后端行为不一致，不能通过“看起来更合理”直接选择一方；应先记录差异并更新领域规格。

## 3. 身份与用户隔离

### 契约 ID：身份-001

- iOS 免登录业务读取和写入必须绑定本地 profile；访问云同步、PWA 或需要身份的托管能力时必须绑定当前认证用户。
- 客户端不得以 URL、路由参数、记录 ID 或账户 ID 推断访问权限。
- 登录用户切换、退出或会话失效时，必须停止旧账号同步并隔离上一用户的内存状态、导航路径、缓存和图片访问结果；本地数据不得被静默归属给另一账号。
- 认证失败和权限失败必须以用户可理解的状态结束，不得进入“看似登录但无法保存”的伪状态。
- 登录不得自动等同于开启同步；业务数据上传需要独立、明确的用户选择。

### 验证证据

- PWA：会话切换、RLS fixture 和登出状态测试。
- iOS：`AppState` 用户状态重置 XCTest、Repository Stub 测试。
- 服务端：RLS、RPC 权限和账号删除迁移测试。

## 3.1 本地数据与同步

### 契约 ID：同步-001

- iOS 本地写入成功即成为当前设备可见事实，不等待网络、登录或 AI。
- 开启同步后，Supabase 保存用户授权的云端副本；PWA 只能展示已进入云端副本的数据。
- 同步必须使用稳定 ID、幂等键、版本或变化序号和删除 tombstone；网络失败不撤销本地成功结果。
- 多设备冲突必须进入领域定义的合并、保留双方或人工处理出口，不允许静默最后写入覆盖高风险事实。

### 验证证据

- iOS 本地数据库和 Repository 集成 XCTest。
- Outbox/Inbox 重复执行、断网恢复和删除 fixture。
- PWA 对未同步数据不可见、同步后可见的跨端验收。

## 4. 记录和数据域

### 契约 ID：记录-001

- 云端支出使用 `transactions`，收入使用 `income_records`，通用生活记录使用 `data_records`；iOS 本地实体可以采用平台存储模型，但必须映射到同一共享契约。
- 动态数据域由 `data_domains` 定义；当前权威系统 key 包括 `expense`、`income`、`sport`、`sleep`、`reading`、`food`、`wallet`。
- 未知或新增数据域不能被客户端静默改写成另一个已知域。
- 记录详情必须保留原始引用和类型信息，不能为了复用 UI 把所有记录压成同一套事实字段。
- `payload_jsonb` 中的原始字段需要可回退展示；未知字段不得导致页面崩溃或数据丢失。

### 验证证据

- 共享域 key fixture。
- PWA 动态域适配器测试。
- iOS `NativeDomainPresentationAdapter` 和通用字段降级 XCTest。
- 未知域、缺失 schema、空 payload 的跨端验收场景。

## 5. 时间、金额和统计

### 契约 ID：口径-001

- 面向用户的日期按照项目既定的上海时区口径解释；具体时间字段和优先级在记录生命周期规格中固定。
- 同一天的边界、月份切换和跨 UTC 事件必须使用统一的日期 key 规则。
- 金额的符号、精度、币种和四舍五入方式不能由页面自行决定。
- 待处理、失败、丢弃和仅预览的数据不得进入确认统计。
- 首页、记录页、数据域详情和分析页在相同筛选条件下应使用同一统计口径。

### 验证证据

- PWA `time-core` 和财务契约测试。
- iOS `NativeLocalDate`、Dashboard 聚合和财务模型 XCTest。
- 共享 JSON fixture 对比两个平台的日期和金额结果。

## 6. 状态、确认与归档

### 契约 ID：状态-001

- 每个业务实体必须列出可进入状态、成功终态、失败态、用户丢弃态和重试出口。
- 任何终态都不能因为网络失败而变成不可恢复的数据死锁。
- 已归档、已确认或已丢弃的记录不能被重复确认而产生第二条正式记录。
- 删除和丢弃必须经过现有确认门禁或等价的明确确认，不得由视觉重构移除。
- 用户确认前，AI 候选只能作为待确认内容展示；确认后才进入正式事实和统计。

### 验证证据

- 领域状态机测试。
- RPC 幂等和重复调用 PostgreSQL fixture。
- PWA/iOS 待处理列表与详情的失败恢复验收。

## 7. 账户和财务影响

### 契约 ID：财务-001

- PWA 和云端路径的账户余额、负债变化以 `accounts`、`account_entries` 以及既定 RPC 结果为权威。
- iOS 本地路径必须以可审计流水或等价操作日志派生余额，不允许页面或同步逻辑直接覆盖余额事实。
- 客户端可以展示预览和校验，但不能绕过当前数据路径的事务性领域契约。
- 支出、收入、账户绑定、还款、撤销和删除的账户影响必须在同一领域规格中说明。
- 首页财务状态、账户页和分析页必须能解释数值来源和更新时间。

### 验证证据

- PWA 账户和财务 occurrence 契约。
- iOS Repository Stub、账户流水和 Dashboard 聚合 XCTest。
- 迁移幂等、RPC 权限和重复调用 fixture。

## 8. AI 识别和表达

### 契约 ID：AI-001

- Hosted AI 路径的上传接收、去重、识别、域路由和表达生成属于服务端职责边界；BYOK 路径可在验证后的客户端 Provider 内直连供应商。
- 识别日志、候选字段、确认事实和表达反馈必须能区分。
- AI 失败、低置信度、缺少字段和无法路由必须进入可见且可恢复的待处理路径。
- 表达内容不能声称没有事实依据的金额、日期、因果或健康结论。
- 用户反馈只能作用于允许的反馈和偏好契约，不能隐式修改历史事实。
- AI 关闭或失败不得阻止手动记录和本地保存；BYOK Key 不得进入业务数据库、Supabase 或日志。

### 验证证据

- Edge Function Deno 测试。
- Expression Planner Node 测试和公开 gold fixture。
- PWA/iOS 表达渲染契约测试。
- Provider 网络拦截、Keychain 和 Disabled 零请求测试。

## 9. 图片和缓存

### 契约 ID：存储-001

- iOS 本地图片使用系统文件保护和本地引用；已同步或 Hosted AI 图片使用受控上传、签名 URL 或等价权限边界。
- 图片签名失败不能清空对应的结构化记录。
- 刷新可以先展示结构化数据，再异步补全图片和补充字段。
- 图片留存、清理、账号删除、本地文件和云端副本属于同一生命周期；未经授权不得仅为云端处理默认长期上传。

## 10. 允许的平台差异

以下差异是允许的，只要不违反前述契约：

- PWA 使用页面、弹窗、底部导航和批量管理；iOS 使用 NavigationStack、Sheet、TabView 和系统权限。
- PWA 采用宽屏信息密度；iOS 采用移动端渐进式披露。
- iOS 可以提供相机、相册、快捷指令和触觉；PWA 通过浏览器能力或文件选择提供对应入口。
- iOS 可以免登录并采用本地优先；PWA 可以继续要求登录并以云端数据为事实来源。
- PWA 不必实现 iOS 的本地数据库和 BYOK，但必须兼容已同步数据的共享字段和状态。
- 两端可以使用不同的视觉主题和动画，但状态、数值、确认门禁和导航语义必须一致。

## 11. 契约变更规则

修改以下任何内容时，必须先更新本文档或对应领域规格，再修改实现：

- 数据域 key。
- 状态枚举或状态出口。
- 金额、日期、时区或统计口径。
- RPC 参数、账户影响或删除级联。
- PWA/iOS 的导航目标语义。
- AI 事实、候选、表达或反馈边界。

每次变更应至少附带一项回归测试或 fixture 更新，并说明 PWA、iOS、Edge 和数据库的影响范围。
