# 芥子规格文档索引

> 状态：试行

本目录保存跨端业务规格、质量规范和领域评审记录。文件名使用中文；稳定场景编号用于测试、提交和交接追踪。

## 通用约束

- [系统总览规格说明](00-系统总览规格说明.md)：系统边界、平台职责、核心实体和长期不变量。
- [跨端一致性契约](01-跨端一致性契约.md)：PWA、iOS、Edge 和数据库必须共享的业务含义。
- [TDD 实施与交接规范](02-TDD实施与交接规范.md)：从中文场景到红灯、实现、绿灯、CI 和交接的统一流程。
- [测试策略与验证门禁](测试策略与验证门禁.md)：各测试层职责、GitHub 门禁和生成式 AI 测试原则。

## 领域规格

- [记录生命周期规格说明](10-记录生命周期规格说明.md)：采集、识别、待处理、归档、删除和跨端场景。
- [记录生命周期规格评审记录](10-记录生命周期规格评审记录.md)：状态机审查、风险、已确认决策和上线阻断项。
- [陪伴表达事实契约](20-陪伴表达事实契约.md)：实体、金额、时间、候选证据和生成式表达必须遵守的事实边界。

## 文档边界

- 通用规范不记录某个任务的当前分支、worktree、临时批次或未提交代码状态。
- 具体场景的红灯、绿灯、CI 结果和未解决风险放在 `docs/spec/执行记录/`，随对应业务分支提交。
- 产品决策写入对应领域规格或评审记录，不反向污染通用 TDD 规范。
- 新增领域规格时先分配稳定编号，再补测试映射和执行记录。
