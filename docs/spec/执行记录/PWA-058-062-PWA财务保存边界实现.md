## 最小实现

- `recordRepository` 新增 `saveExpense` / `saveIncome`，只映射两个 canonical RPC 参数并复用正式记录 DTO。
- 新增 Finance Save Feature，以用户、kind 和 create/edit ID 管理 inflight Promise，并通过 generation 与当前用户检查隔离旧会话结果。
- Feature 将权威 DTO 本地收敛与写后刷新拆开；刷新异常返回 `accepted + refreshStatus: failed`。
- Store 的 manual/edit 支出和收入统一委托 Feature，使用 `result.record` 对正式记录数组按 ID upsert。
- `resetUserData` 重置 Finance Save Feature；账户和未绑定列表刷新增加预期用户 guard 与可选结构化失败出口。
- staging、待补全和账户补绑路径保持原状；PWA-063 冻结特征测试仍验证补绑直连未被提前迁移。
- Release Validation 增加 `test:finance-save` 专项门禁。
