# LOCAL-AI-001 / LOCAL-AI-003 Hosted 传输同意

- 目标：旧版本保存过 Hosted 模式的设备升级后，必须读完新的发送说明并主动同意，App 和快捷指令才能再次使用 Hosted。任意设备关闭 Hosted 后，后续图片继续走本机收件箱。
- 现状：旧版只记住模式，图片识别设置没有在启用时列明陪伴请求发送的数据。
- 契约：[AI 供应方与 BYOK 安全契约](../模块/iOS本地优先/AI供应方与BYOK安全契约.md)。
- 范围：iOS 的模式读取、设置确认、注册提示和内置政策，以及公开中英文政策。PWA 和 Edge 的处理逻辑维持原有契约。
- 验证层：iOS 模式存储接口。使用真实模式存储和隔离的 UserDefaults，将新增 XCTest 的同一组断言在命令行运行。旧代码在读取旧设置时实际返回 Hosted，预期为关闭；加入版本化同意后，旧设置关闭、同意后启用和关闭后停用均通过。
- 模拟器：iPhone 17e、iOS 27.2，定向 XCTest 通过（1/1）。
- 待验收：设置弹窗及快捷指令完整流程。更新后的公开政策及 TestFlight 构建尚未发布。
