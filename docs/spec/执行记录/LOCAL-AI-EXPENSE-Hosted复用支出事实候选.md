# LOCAL-AI-EXPENSE Hosted 复用支出事实候选

- 目标：让 Hosted 支出陪伴按 PWA 的规则计算同商户当天笔数、累计金额和上次同名记录间隔。
- 权威：ADR-003、CORE-024、CORE-031 至 CORE-038。iOS 从当前本机账本挑出最多 7 条相关历史证据，Hosted 使用原有 PWA 规则构造并选中详情候选。仅在本机交易日前 30 天范围内取证。
- 红灯：两笔 5 元和 2 元，旧 Hosted 只支持校验单笔数字，直接提交聚合会报 `number_value_mismatch`。新增对照用例在共享候选入口实现前无法运行。
- 绿灯：iPhone 17e 模拟器 38 项通过，包含干扰商户超过原先截断上限且存在商户名称变体的请求断言。Deno 新入口与既有 Action 17 项通过，既有候选契约的 5 项在 `--no-check` 下通过（旧测试的联合类型字面量推断告警）。生产 Edge 入口通过 `deno check`。PWA 相关共享核心 6 组通过。
- 范围：共享 Prompt 沿用现状。旧客户端及其他域维持原有入口。新请求以同格式合并当前事实和最多 7 条证据，不查云端账本。
- 待验收：真机 Hosted 模型文案、通知与详情的独立选材，以及生产配置。此改动仅在本地分支，未提交、推送或发布。
