# REC-005-IOS 待补全账单批量确认

- REC-005-IOS-BATCH-A：从待处理页打开当前列表里的本机待补全账单，展示已识别的日期、金额、渠道、分类和支付方式。默认不选中账单，由用户选择或全选可确认项。
- REC-005-IOS-BATCH-B：用户可统一填写缺失的渠道、分类或支付方式，已有值保留。仍缺必要字段、疑似重复或需确认收支类型的账单走单笔补全。批量逐笔复用本机确认事务，写入前核对工作区和账单快照。正式账目保留原图和已有 AI 文案，刷新本机表达证据，避免同时为历史账单发起大量新的 Hosted AI 请求。
- PWA 对照：收件箱的选择、全选和归档只适用于普通中转记录，待补全账单显示「账单需要逐条补全」。iOS 在这个入口增加待补全账单专用批量操作。
- 验证：29 项本机识别测试已通过。新增数据库场景覆盖缺失值批量填写、已有字段保留、疑似重复、过期快照和重复确认。页面展示已保存和未保存数量，未保存的账单保留在待处理。
