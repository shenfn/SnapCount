# 表达核心渲染契约规格说明

> 模块编号：CORE-011
>
> 状态：已完成；PR #63 于 `3390f9e` 合并

## 1. 目标

将表面渲染、曝光事件和曝光历史规则迁入生产共享核心，使 Edge、fallback 和 Planner Lab 使用同一份渲染契约，并消除 A2 最后一条生产对 `tools` 的反向依赖。

## 2. 范围

- 迁移 `SURFACE_RENDER_CONTRACTS`、`buildRenderPlans`、`buildExposureEvents` 和 `compileExposureHistory`；
- 新增并统一使用 `SURFACE_RENDER_CONTRACT_VERSION`；
- 保留 shortcut、PWA pending、record detail、weekly report 四个表面的现有字段契约；
- Lab 原路径改为兼容 wrapper；
- Edge Planner 改为直接引用生产核心；
- Edge Delivery/Shadow 改为引用共享版本常量；
- 新增 Node/Deno 共享 fixture、wrapper 和 Edge 静态契约。

## 3. 非目标

- 不新增、删除或重命名 surface、slot、字段路径或 delivery state；
- 不改变候选选择、评分、文案、证据内容或客户端 UI；
- 不把 Lab 模拟曝光函数接入生产数据库写入；
- 不改变 `occurredAt` 缺失时的当前时钟 fallback；
- 不修改 SQL fixture 中已持久化的版本字面量；
- 不修改 PWA/iOS、数据库迁移、生产配置或部署；
- 不在本切片拆解 Edge `index.ts` 或 `expression-delivery.ts` 的业务编排。

## 4. 行为场景

| 编号 | 行为不变量 | 测试层 |
|---|---|---|
| CORE-077 | 已选择候选按 surface 契约投影固定槽位、字段路径、结构化值和 canonical text | Node/Deno fixture |
| CORE-078 | 未登记 surface 必须抛出明确错误，不能静默生成无契约计划 | Node/Deno fixture |
| CORE-079 | simulation exposure 使用 `rendered_preview`、不计 novelty，并保留显式 occurredAt | Node/Deno fixture |
| CORE-080 | real exposure 使用 surface delivery state、计入 novelty，并保留版本和 key | Node/Deno fixture |
| CORE-081 | preview、非计数或非白名单生命周期事件不得进入 exposure history | Node/Deno fixture |
| CORE-082 | exposure/dedupe key 均进入 scoped history，count 累加且 last_shown_at 取最新 | Node/Deno fixture |
| CORE-083 | 版本常量由生产核心唯一拥有，Lab wrapper 同引用，三个 Edge 文件不再依赖或重复 `tools` 规则 | Wrapper + 静态契约 |
| CORE-084 | 同一 fixture 在 Node/Deno 输出一致，生产 `tools` 反向依赖为 0 | 双运行时 + 架构门禁 |

## 5. 实施顺序

1. 合并边界评估、Spec、ADR、执行记录和交接文档 PR。
2. 新增 CORE-077 至 CORE-082 共享 fixture，确认生产模块缺失时有效红灯。
3. 整体迁移 render contract，导出版本常量，Lab 改为 wrapper。
4. 改 Edge Planner import，并让 Delivery/Shadow 使用共享版本常量。
5. 删除架构基线最后一条例外，运行 Node/Deno、旧 render 测试、完整 Planner、Edge check 和治理门禁。
6. CI 全绿后更新 A2 完成证据和下一阶段入口，不在同一 PR 开始 PWA/iOS 重构。

## 6. 完成定义

- 生产对 `tools/` 的 import 为 0，架构基线例外为空；
- 四个旧导出和新增版本常量由生产核心拥有；
- CORE-077 至 CORE-084 有共享 fixture 或静态契约映射；
- Node/Deno、旧 render、完整 Planner、Edge check 和治理门禁通过；
- 版本字符串的运行时权威只有共享常量一处；
- 阶段索引、执行记录、ADR 和交接快照已更新；
- 未执行生产部署、数据库迁移、PWA/iOS 改动或 worktree 清理。
