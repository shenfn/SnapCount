## 1. 目标与范围

将 iOS 表达反馈提交的认证、命令 identity、并发复用、reset/generation stale 和结果分类收拢到纯 Swift `FeedbackSubmissionUseCase`。页面继续调用 AppState 兼容入口；Edge action、反馈参数和服务端记录不变。

本片不刷新详情、账户、dashboard、余额、钱包或中转列表，不迁移表达计划生成/曝光确认，不重构正式记录保存/删除和图片签名。

## 2. 契约

### Use Case 输入

- `recordId`：正式记录原始 ID，不能为空；
- `feedbackIdentity`：当前可提交反馈的 render identity，不能为空；
- `choice`、`freeText`、可选 `exposureEventId`：沿用现有反馈语义；
- session/context provider：提供 access token、user id、generation 和 signed-in 状态。

### Use Case 输出

```text
accepted
rejected(unauthenticated | invalidInput)
failed(message)
stale
```

`accepted` 只表示服务端反馈提交请求成功；不代表生成新文案，也不触发任何财务刷新。

### Repository 边界

窄协议只负责调用既有 `submit_expression_feedback` transport。它接收 `recordId`、`choice`、`freeText`、`exposureEventId` 和 access token；不接收客户端 `userId`，不拥有页面状态，不实现并发、generation 或重试策略。

## 3. 并发与会话隔离

1. 命令 identity 至少包含 `userId + recordId + feedbackIdentity`；同 identity 的 in-flight 调用复用一个 Task。
2. 不同记录或不同反馈 identity 不互相阻塞；同记录不同 identity 不复用旧命令。
3. transport 前、返回后都检查 `userId + generation + isSignedIn`。
4. `reset()` 清除本地 in-flight 引用并递增内部 generation；已经发出的服务端请求不能取消，但其返回只能是 `stale`。
5. stale 不投影 `submitted/failed`，不写当前页面状态，也不触发刷新。

## 4. AppState 兼容边界

AppState 继续负责：

- 从 `selectedRecordDetail` 和 feedback identity 选择可提交的 `NativeAIFeedback`；
- 调用 Use Case 并将结果投影到现有 `NativeAIFeedbackReviewState`；
- 页面消息与 `submitRecordFeedback(...)` 兼容入口；
- 用户注销/切换时调用 `feedbackSubmissionUseCase.reset()`。

移出 AppState：

- 提交命令 identity、Task 复用与冲突；
- session/generation stale 判断；
- accepted/failed/stale 结果分类。

## 5. 场景矩阵

| 场景 | Given / When / Then 不变量 | 测试层 |
|---|---|---|
| A4-IOS-010A | 未认证、空记录 ID、空 feedback identity 在 transport 前 rejected；Repository 不调用 | Use Case XCTest |
| A4-IOS-010B | 同一命令并发提交复用一次调用；不同记录/identity 可独立提交 | Use Case XCTest |
| A4-IOS-010C | choice、free text、exposure event id 原样传给窄 Repository；不增加 user_id | Repository XCTest/源边界 |
| A4-IOS-010D | 服务端失败返回 failed，不投影 submitted，不触发刷新 | Use Case/AppState XCTest |
| A4-IOS-010E | reset 或用户切换使旧结果 stale，不更新新会话状态 | Use Case XCTest |
| A4-IOS-010F | accepted 只投影 submitted，不刷新财务/详情/表达计划状态 | AppState/副作用边界 |
| A4-IOS-010G | RecordsView/InboxView 仍通过 AppState 入口；页面不直接依赖 Repository | 源边界脚本 |
