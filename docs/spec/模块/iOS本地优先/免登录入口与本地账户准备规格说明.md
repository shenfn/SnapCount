# iOS 免登录入口与本地账户准备规格说明

> 规格编号：LOCAL-002-UI
>
> 状态：提议，待红灯
>
> 上游：`LOCAL-PLAN-001`、`LOCAL-DATA-001`、`LOCAL-002`、`LOCAL-002-APP`

## 1. 目标

让没有 Supabase session 的新用户直接进入一个可实际完成“创建账户 -> 记录消费 -> 重启后查看”的本地闭环，同时不破坏已有登录用户的云端五 Tab 体验。

## 2. 状态定义

L1 过渡期使用两个应用表面：

| 表面 | 判定 | 可见能力 |
|---|---|---|
| 本地安全壳 | 无有效云端 session | Records、本地 Settings、本地账户准备、手工消费 |
| 旧云端壳 | 已恢复有效云端 session | 现有 Today、Inbox、Records、Insights、Settings |

这不是两套领域实现。本地写入始终由 Local Use Case 负责；旧云端壳只作为迁移前兼容表面，L2/L3 后收敛。

## 4. 应用层契约

现有 `LocalExpenseUseCaseProtocol` 可按最小方式扩展，或由等价的同层 Use Case 承担；不得由 AppState 直接访问 Repository：

```swift
struct LocalExpenseWorkspace {
    let profile: LocalProfile
    let accounts: [LocalAccount]
}

struct LocalAccountSetupCommand {
    let id: UUID
    let name: String
    let kind: String
    let openingBalanceText: String
    let createdAt: Date
}

protocol LocalExpenseUseCaseProtocol {
    func prepareWorkspace() async throws -> LocalExpenseWorkspace
    func createAccount(_ command: LocalAccountSetupCommand) async throws -> LocalAccount
    func month(_ monthKey: String) async throws -> LocalExpenseMonth
}
```

- `openingBalanceText` 用 Decimal 转整数分，允许 0，不允许负数、NaN、溢出或隐式 `Double`。
- 首片账户类型只允许 `cash`、`wallet_balance`、`debit_card`。
- Use Case 必须隐含 active profile；View/AppState 不传任意 profile ID。
- 账户创建后余额仍由 opening balance 与账户流水确定性派生。

## 5. UI 与导航契约

### 5.1 Root

- bootstrapping 期间继续显示加载态。
- 无 session 时显示本地 TabView，仅包含 Records 和本地 Settings。
- 本地允许的选中项只有 Records/Settings；若状态仍是 Today/Inbox/Insights，进入本地壳时规范化为 Records。
- 有 session 时保持现有五 Tab 和导航栈，不在本片重构旧云端壳。

### 5.2 Records

- 本地模式只展示消费种类和本地月份。
- “账户”进入本地账户列表；隐藏“数据域”。
- 本地记录首片以不可导航行展示；详情 UI 在独立切片实现。
- 本地模式不执行远端详情预取。

### 5.3 账户准备

- 无账户点击新增时先显示账户准备表单。
- 字段：名称、类型、期初余额；币种固定 CNY。
- 创建成功后继续进入消费表单，并选中新账户。
- 用户取消账户准备时不创建账户、不打开消费表单。

### 5.4 本地消费表单

- 隐藏记录类型切换，只显示 expense 字段。
- 账户必选，不提供“暂不绑定”。
- 不调用 `loadFinanceVocabulary`；可使用现有静态选项。
- 保存成功文案明确为“已保存在本机”。

### 5.5 本地 Settings

- 展示本地模式身份、仅本机存储、主题、法律文档和版本。
- 云同步显示“尚未开启”，不提供登录按钮。
- 隐藏 Hosted AI、快捷指令、云端数据删除、云端设置加载和云端导出入口。

## 6. 网络闸门

本地安全壳以下动作必须保持云端调用数为 0：

- 启动与 profile/account/month 准备；
- Records 刷新和月份切换；
- 创建账户和创建消费；
- 展示本地 Settings；
- 点击本地记录行。

网络闸门覆盖 Supabase Auth、PostgREST/RPC、Storage、Edge、远端图片和财务词表。

## 7. 实施顺序

1. UIA 红灯：Root 表面、允许 Tab、本地月份读取、远端详情/设置闸门。
2. UIA 最小实现并完成完整回归。
3. UIB 红灯：账户创建命令、金额解析、无账户出口、表单远端闸门。
4. UIB 最小实现并完成完整回归。
5. 写回执行记录、交接快照和阶段索引。

## 8. 完成定义

- 无 session 可进入 App 并完成创建账户、记录消费、重启恢复和查看月份。
- 本地闭环没有任何业务数据访问项目云端。
- 已登录旧用户五 Tab 和云端能力未回归。
- 没有静默账户、静默上传、静默绑定或本地/云端事实混合。
- Node 边界、本地专项 XCTest、完整 XCTest、macOS Build、治理和架构门禁通过。

本规格完成后仍不得宣称同步、登录绑定、本地详情、其他域、AI Provider 或 App Store 发布准备已完成。
