## 1. 场景矩阵

| 场景 | 行为不变量 | 测试层 |
|---|---|---|
| PWA-052 | 月度支出与待补全支出的过滤、排序、上限和 DTO 映射由 Record Repository 唯一持有；不传 `user_id` | Repository 行为 |
| PWA-053 | 月度收入与最近收入的过滤、排序、上限和 DTO 映射由 Record Repository 唯一持有；收入读取失败保持结构化失败 | Repository 行为 |
| PWA-054 | 月度通用记录按上海时区发生时间查询，`occurred_at` 缺失时以 `created_at` 兜底；上限保持 120 条 | Repository 行为 |
| PWA-055 | 未绑定支出/收入复用同一 DTO 与月份规则；Repository 不拥有账户推荐、绑定、余额或页面数组 | Repository/Store 特征测试 |

## 2. 范围

- 新增正式记录读取 Repository，负责 `transactions`、`income_records` 和 `data_records` 的查询 transport。
- 将交易、收入和通用记录的数据库行到 PWA DTO 映射收敛到 Repository 可复用出口。
- `useStore.loadData` 改为消费结构化 Repository 结果。
- `loadUnboundRecords` 改为消费 Repository 结果，保留页面 loading、提示和数组写入。
- 新增专项测试脚本并挂入 Release Validation。

## 3. Store 保留职责

- Promise 并发编排与 current user/run guard。
- 决定支出失败是否阻断主加载，以及收入、通用记录失败是否局部降级。
- 写入 `bills`、`pendingBills`、`incomeRecords`、`recentIncomeRecords`、`dataRecords` 和派生数组。
- 图片签名、账户读取、账户推荐、绑定、余额、还款候选和页面提示。

Repository 返回 `accepted/failed` 结构，不把失败伪造成成功空数组；Store 根据现有行为决定失败出口。

## 4. PWA-056 延期裁决

PWA-056“已处理中转目标按显式类型读取”不在本片实现。只读核对证明：

- `staging_records` 只持久化 `target_record_id` 和可选 `target_domain_id`；
- `detected_domain_key` 是识别结果，不是用户最终归档类型；
- 支出与收入的 `target_domain_id` 均为空，无法互相区分；
- 最终 `corrected_domain_key` 只保存在 `user_routing_feedback`。

因此，直接按 `detected_domain_key` 读取会在用户纠正域后打开错误表。PWA-056 必须先单独评估以下两种契约之一：

1. 已处理列表通过受测试的关系查询返回最终 `corrected_domain_key`；
2. 数据库在中转记录持久化不可歧义的 `target_kind/target_reference`。

在该契约落地前，保留现有已处理目标探测行为，不在本片制造静默回归。

## 5. 非目标

- 不修改 `stagingRepository`、已处理目标跳转、Staging RPC 或数据库。
- 不修改正式记录创建、编辑、删除、账户绑定、账户流水或 wallet 快照。
- 不迁移 `accounts`、图片签名、还款周期、财务词表或表达缓存失效。
- 不删除 `loadData`，不新建多个互相写状态的 Store。
- 不修改 iOS、Edge、生产配置或真实数据。

## 6. TDD 顺序

1. 运行中转读取、待处理队列、时间显示、治理与 PWA build 基线。
2. 为 Repository 查询参数、DTO、失败结构和禁止 `user_id` 写红灯。
3. 为 `useStore` 不再直查三张正式记录表、未绑定读取复用 Repository 写红灯。
4. 写最小 Repository 与 `useStore` 接线，保留 Store 的失败分层和用户/run guard。
5. 运行正式记录专项、中转回归、安全、治理、架构和 PWA build。

## 7. 完成定义

- PWA-052 至 PWA-055 有有效红灯、最小实现和绿灯记录。
- `loadData` 不再直接查询 `transactions`、`income_records` 或 `data_records`。
- `loadUnboundRecords` 不再复制这三类查询或 DTO 映射。
- 财务和通用记录映射各自只有一份生产实现。
- `accounts`、保存、删除、wallet、Staging 和图片签名未被本片吸收。
- PWA-056 的缺口和下一步仍在阶段索引及交接中可恢复。
