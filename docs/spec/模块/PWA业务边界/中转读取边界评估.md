# PWA 中转读取边界评估

> 任务：CLEAN-001/A3、PWA-047
>
> 基线：`9d7e9ad`（PWA-042 至 PWA-046 PR #79 合并提交）
>
> 状态：历史评估；PR #80 已通过全部门禁并合并

## 1. 结论

下一实现切片已按本评估收拢中转读取 transport 和 DTO 映射：在现有 `stagingRepository` 增加开放队列与已处理列表查询，保留 `loadData` 的并发编排、current user/run guard 和页面状态写入。

本片不拆正式记录，不迁移图片签名，不生成还款候选，也不重写 `loadData`。这样可以先消除 `useStore` 对 `staging_records` 的直接查询，同时不把中转读模型与全局账户、财务记录和图片权限混成一个大 Repository。

## 2. 现状证据

| 位置 | 当前行为 | 边界判断 |
|---|---|---|
| `useStore.loadData` 主查询 | 与交易、收入、通用记录、账户并行直接查询开放 `staging_records` | 查询 transport 应归 Staging Repository；并发编排仍属于 Store 的兼容门面 |
| `loadData` staging 映射 | 在 Store 内把数据库列映射为 `stagingRecords`，补充 `repaymentCandidate: null` | DTO 映射可下沉；还款候选计算不能随读查询一起下沉 |
| `loadProcessedStaging` | 再次直接查询 `staging_records` 的 `archived/discarded`，并映射 `processedStagingRecords` | 应与开放列表共享 Repository 查询边界，但保留当前加载时序 |
| `hydrateStagingImages` / 已处理图片加载 | 通过通用签名 URL helper 处理中转图片 | 暂不归入 Staging Repository，避免复制图片权限和签名策略 |
| `loadRepaymentCycles` | RPC 生成/读取还款周期，再为中转记录构造候选 | 暂不迁移；它依赖账户还款语义，不是中转读取 transport |
| 丢弃/归档/重试 Feature | 已分别进入 Repository/Feature，当前 PR #79 已合并 | 读取切片只消费这些已收拢的中转写边界，不回改写路径 |

## 3. 候选实现范围

建议下一实现 Spec 使用四个场景编号：

| 场景 | 目标不变量 | 测试层 |
|---|---|---|
| PWA-047 | 开放中转查询固定状态过滤、排序和队列上限，Repository 不传 `user_id` | Repository 行为 |
| PWA-048 | 已处理查询只读取 `archived/discarded`，排序和上限稳定，Repository 不拥有页面数组 | Repository 行为 |
| PWA-049 | Store 仍负责一次 `loadData` 的并发编排和 current user/run guard；旧查询不能写入新用户 | Store/Session 特征测试 |
| PWA-050 | 图片签名与还款候选继续由现有 helper/账户边界负责，Staging Repository 不复制这两套规则 | 源契约/架构边界 |

PWA-047 至 PWA-050 只是下一实现切片的候选场景；本评估不提前创建代码或把它们标记为已实现。

## 4. 非目标与风险

- 不抽离交易、收入、通用记录、账户查询或正式记录写入。
- 不修改 `staging_records` 查询语义、数据库函数、RLS、Edge、iOS 或生产配置。
- 不把图片签名 URL、还款周期或 `repaymentCandidate` 作为 Repository 的 DTO 规则。
- 不以“移除所有 `loadData` 查询”为完成标准；本片完成标准是中转 transport 有唯一归属且旧用户响应仍受 Store guard 保护。
- 现有 `loadData` 仍是较大的兼容门面，后续需要另行评估正式记录读模型，不能在本片顺手重构。

## 5. 进入实现的门禁

1. 先建立 PWA-047 至 PWA-050 的实现 Spec 和 Repository/Store 特征测试。
2. 先证明当前开放/已处理列表的过滤、排序、映射行为，再实现最小 transport。
3. 本地专项、PWA build、治理、安全和架构检查通过后再创建 PR。
4. PR 合并后才把阶段索引从“评估进行中”推进到“中转读取实现进行中”。
