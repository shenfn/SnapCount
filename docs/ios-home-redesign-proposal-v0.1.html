现状首页的问题一句话概括：所有信息一个音量。两大卡片轮播（财务 270pt + 数据域 246pt）功能同质、入口重复，"首页组件"管理条还占着首屏黄金位置。本方案把「财务状态 × 数据域」合并为一个有呼吸感的主卡 + 指标网格结构，引入参考设计的杂志刊头式排版，让首屏有且只有一个主角。

02参考设计拆解：它为什么好看

你在抖音看到的这个纪念页，值得借的不是皮，是排版的纪律。拆出 6 条可迁移的手法：

① 杂志刊头（Masthead）
顶部小字日期 + 同步时间，然后一行大号衬线问候「Good evening, 敏敏」。时间感知 + 直呼其名，一秒建立"这页是写给我的"的感觉。→ 我们有时段 token（7 时段+45min 插值），天然支持。
② 一句话情报行
问候下方一行小字「阴 27° 28~34° · 降雨 76%，带伞」——当天最该知道的事压缩成一行，不用点开任何卡片。→ 对应我们的"今日已记 X 条 · 支出 ¥Y · Z 条待处理"。
③ 唯一主角的大数字
「Day 35」衬线巨号数字，全页视觉锚点，其余全部让位。→ 我们的主角应该是「今日支出」或「本月结余」——用户自己的 Day N。
④ 细分隔线统计行
birthday 164 | anniversary 331，竖细线分隔的多栏统计，密度高但不吵。→ 现金 / 本月支出 / 待还款三栏，正好替换"现金与还款"整张卡。
⑤ 深色引用卡做情绪对比
「Today's Whisper」深底金字，是全页唯一重色块，AI 生成的一句话让页面有了灵魂。→ 我们的 space #17312D + gold #DCBF74 正好是这个角色，「芥子低语」AI 每日一句。
⑥ 迷你指标砖 + 迷你图
Steps 580 / Heart Rate 114 两列小砖：标签、大数字、单位、sparkline、区间小注。→ 财务+数据域 11 种洞察卡全部降维成这种砖，用户自选 4 块。
气质契合度：参考设计的米白纸感、衬线大数字、细金线，与芥子「宣纸上的数字生活」DNA 是同一路数——借鉴它不会显得像抄，反而像回家。

04参考视频逐帧拆解：它"舒服"在哪

对 45.9s 视频按时间轴抽帧分析（开头 4fps、正文 0.5fps、两次切换交互 3fps），你感觉到的"像 iPhone 原生组件"，本质是六种有据可依的 iOS 原生动效惯用法，全部可以用 SwiftUI 一行级 API 复现：

4.1 开屏：一根线写完一个字

0–2.5s：奶白底上，一根细线像钢笔签名一样自绘出手写体 "Claude"（典型的 stroke-dashoffset 描边动画）；随后字母崩解，残线收拢成一条水平分割线，首页随之淡入——开屏的线没有消失，它变成了版面的一部分。这个"元素不消失、而是归位"的手法，是整个视频最高级的一笔，§06 的开屏方案曾化用它（现已后置，留作素材）。

4.2 交互：六种原生手感的来源

视频中观察到的本质手法SwiftUI 实现用在芥子哪里
Diary 页「敏敏 / Claude」分段开关，黑底滑块跟手滑动匹配几何：滑块是同一个 View 在两个位置间形变matchedGeometryEffect + spring月份切换、域筛选、低语卡多句轮播指示器
切换分段/刷新时，旧内容模糊→新内容聚焦（抽帧可见明显的动态模糊中间态）模糊替换过渡，iOS 17+ 系统级惯用法.contentTransition(.blurReplace)，配 .animation 触发主卡大数字切日期、指标砖数据刷新、低语卡换句——这是"原生感"性价比最高的一招
数字变化时逐位滚动而非跳变数字文本过渡.contentTransition(.numericText(countsDown:))支出金额、待办计数、域 chips 数字
卡片按下整体轻微回缩、松手弹回弹簧按压scaleEffect(0.97) + spring(0.42, 0.82)已有 JieziPressableButtonStyle，沿用即可
滚动时卡片错峰入场、大列表内容分层浮现滚动过渡.scrollTransition(.animated) 调 opacity/offset日记流日卡、指标砖首屏入场
切换/勾选瞬间有轻微"咔哒"感触觉反馈（haptics token 已定义）.sensoryFeedback(.selection / .impact)分段切换、记账成功、待办勾销
结论：它的舒服不靠任何黑科技，靠「spring 曲线统一 + 元素连续不跳变 + 触觉点缀」的纪律。我们的 motion token（fast 150 / normal 250 / slow 400 / spring 0.42-0.82）已经覆盖了全部所需参数。v0.3 起这些接线不再后置：blurReplace / numericText 随 Phase 1 刊头与 Phase 2 主卡同步落地，scrollTransition / sensoryFeedback 随日记流与待办带落地。
