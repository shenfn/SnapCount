# 表达规划器真实数据回放

该脚本只读线上数据，将敏感快照与回放结果写入仓库外、已被主仓库 `.gitignore` 排除的目录：

```text
D:\Business\count\别提交到github上\reference\算法讨论\表达规划器真实数据回放
```

## 在线抓取并回放

在独立工作树根目录执行：

```powershell
node --env-file="..\..\.env.local" tools/ai-validation/expression-planner/replay-production-regression.mjs
```

可选参数：

```text
--since=<ISO 日期或时间>  只抓取该时间之后创建的数据
--include-tests            包含 payload_jsonb.test_meta 测试记录
--output-root=<目录>       覆盖本地敏感输出根目录
```

## 使用固定快照离线回归

算法调整后，不重新读取线上数据，直接对同一份快照回放：

```powershell
node tools/ai-validation/expression-planner/replay-production-regression.mjs `
  --mode=offline `
  --input="D:\...\source.snapshot.json"
```

每次运行生成独立目录，包含：

- `source.snapshot.json`：按用户伪名化的只读输入，不包含图片、图片路径和哈希。
- `replay-results.json`：逐条候选、评分、选择和旧 Shadow 对照。
- `summary.json`：可用于版本间自动比较的聚合指标。
- `feedback.snapshot.json`：点评与曝光关联，仅保存在本地敏感目录。
- `zero-candidates.json`：本地 Planner 仍为零候选的记录，供下一轮修复。
- `报告.md`：人工阅读摘要。
- `逐条查看.html`：直接浏览真实记录、旧 Shadow 与本地候选，不需要启动服务。

## 两次运行自动对比

```powershell
node tools/ai-validation/expression-planner/compare-production-regression.mjs `
  --baseline="D:\...\回放-基线" `
  --current="D:\...\回放-当前"
```

需要在出现“原来有候选、修改后变成零候选”时返回非零退出码，可增加：

```text
--fail-on-zero-regression
```

## 因果边界

- 每条记录只读取其发生时间之前的同用户历史。
- 不读取当前时点 `user_domain_profiles`，避免历史回放使用未来画像。
- 原始记录用于事实与上下文重建，不被当作偏好标签。
- 只有关联到 `record_detail` 真实曝光的点评计入当前偏好训练准备度。
